# 텍스트 제출 표본

모든 파일은 해커톤 시연용 **합성 데이터**이며 협력사명·일정·인원은 가상이다(`가상-…`).
"협력사가 정해진 형식의 텍스트로 냈을 때" 추출 정확도를 재기 위한 표본이다. 통일 양식 표본 5건(`../uniform/`)의 작업 13건을 그대로 옮겼다.

다시 만들기: `cd app/backend && uv run python ../samples/make_text_samples.py`  
측정: `cd app/backend && uv run python ../samples/accuracy.py --samples ../samples/text --mode llm`

표가 없어 표 규칙 경로(`--mode rules`)로는 읽히지 않는다. LLM 경로로만 잰다.

## 텍스트 양식 규칙

- 텍스트 파일 1개 = 업체 1곳, UTF-8, 줄바꿈 `\n`, 코드 울타리 없음
- 파일 머리: 첫 줄 `작업계획서 (합성 데이터)`, 둘째 줄 `업체명: <업체>`. 업체명은 여기에 한 번만 적는다
- 작업 1건 = `[작업 N]` 한 줄과 `칸 이름: 값` 줄들. 작업 사이에 빈 줄 하나
- 칸 이름과 순서는 통일 엑셀의 머리글 행을 따른다: `기준 일정 ID` · `작업명` · `구역` · `시작일` · `종료일` · `주야간` · `인원` · `위험작업` · `선행작업` · `비고`
- 값은 엑셀 셀의 값을 그대로 옮긴다. 시작일·종료일은 YYYY-MM-DD, 인원은 정수, 빈 셀은 칸 이름 뒤를 비운다(`비고: `)
