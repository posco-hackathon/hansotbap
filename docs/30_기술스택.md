## 3. 지켜야 할 구조 원칙
- **LLMProvider 하나로 감싼다.** Claude와 LM Studio를 같은 인터페이스 뒤에 두고 설정으로 바꾼다. 발표 포인트: "협력사 계획서를 외부로 내보내기 어려운 현장은 사내 로컬 모델로 돌릴 수 있다" (현업 적용 가능성).
- **판정은 규칙, LLM은 추출·설명.** F2·F8 누락 판정·F9 점수는 규칙 코드로 하고 pytest로 검증한다.
- **모든 판정에 근거.** 규칙 ID, 법 조문, 원문 문장을 응답에 담는다.
- **합성 데이터 표시.** 화면에 "합성 데이터" 표시, 협력사명은 가상.
- **API 키는 환경변수로.** 코드·저장소에 넣지 않는다.

## 4. 화면 구성 (F3)

### 4.1 메인: 시간표형 간트 (원청 대시보드 = 현재상황판)
- 가로 07~19시, 30분 칸. 세로는 구역(위→아래 순서, `zones.csv`)
- 구역별 업체 막대, 지금 선, 겹침 구간 색 띠(F2 충돌·F9 위험 시간대), 아래에 조치 카드
- 상단 요약: 업체 수·인원·겹침 건수 / 음성으로 묻기(F6)
- 조치 카드로 부족한 부분은 충돌 목록·구역 클릭 상세 패널로 보완

### 4.2 고로 3D / 층별 2D 도면
- **스타일:** 클레이(점토) 느낌, 구역별 색 구분. 저사양 PC에 맞춘 단순 도형(원기둥·원뿔)
- **고로 본체:** 노정, 노흉, 노복·조안, 풍구, 노저를 원기둥·원뿔 층으로 쌓는다. 층을 모두 보여주고 `zones.csv` 구역과 1:1로 맞춘다.
- **층 선택:** 층을 고르면 그 층을 2D 도면 또는 3D로 전환해 본다.
- **주변 설비:** 열풍로, 가스청정(제진기), 하강관, 출선장, 크레인 구역을 단순한 박스·관으로 둔다.
- **충돌 표시:** 빨강(금지)·주황(조건부)으로 칠하고, 위아래 겹침은 두 층 사이에 세로선·화살표로 표시한다.
- **시간 슬라이더:** 움직이면 구역 색이 바뀐다(F9 위험 시간대).
- **클릭 상세:** 구역을 누르면 그 구역의 작업·충돌·근거 조문 패널이 열린다.
- **순서:** 3D를 먼저 개발하지만 메인 화면은 간트다. 3D가 늦어도 간트로 시연할 수 있다.

### 4.3 나머지 화면 (기획서 6.1)
계획서 업로드(추출 표·원문 하이라이트·수정) / 충돌 상세(규칙 ID·법 조문·원문·조정안·적용 버튼) / 협력사 화면(내 작업·나와 겹친 충돌·표준서·공지) / 챗봇 패널(화면 옆 고정) / TBM 확인(녹음 업로드·전달 체크리스트) / 이력(제출·변경·조정 기록, 내보내기)

## 5. 구조

```
[작업계획서 HWPX·엑셀·PDF]   [작업표준서 폴더]   [TBM 녹음]
            ▼                      ▼                ▼
[FastAPI]
  ├─ parsers   (PDF·엑셀·HWPX → 텍스트)
  ├─ llm       (LLMProvider: Claude | LM Studio, 추출·설명만)
  ├─ rules     (F2 판정, F8 누락, F9 점수)
  ├─ search    (F8 임베딩 인덱스, FAISS/Chroma)
  ├─ stt       (F7 Whisper large-v3-turbo / large-v3)
  └─ db        (SQLite: 업체·작업·기간·구역·인원·판정 결과)
          │ REST
[React 프론트 — 표시 전용] 원청 화면 / 협력사 화면 (역할 선택)
  ├─ 시간표형 간트 (자체 구현, CSS Grid)
  ├─ 고로 3D·2D 도면 (three.js)
  └─ 챗봇 UI
```
- 판정은 계획서가 제출되는 순간 실행한다(제출 시점 대조, 실시간 추적 아님).
- 동시에 제출되면 먼저 들어온 계획을 기준으로 대조한다.
- 판정이 끝나면 화면을 한 번 강제 새로고침해 반영한다.
- 권한: 원청은 전체, 협력사는 자기 업체 데이터만. 공유 범위는 원청이 공유하기로 한 것(인접 위치 작업, 위험 요소, 작업 인계 조건)만.

## 6. 폴더 구조

```
app/
  backend/
    api/          # FastAPI 라우터
    parsers/      # pdf, xlsx, hwpx → 텍스트
    llm/          # provider(Claude, LM Studio), 프롬프트, 출력 스키마
    rules/        # F2 판정, F8 누락 판정, F9 점수 (pytest 대상)
    search/       # F8 임베딩·인덱스
    stt/          # F7 Whisper large-v3-turbo / large-v3
    db/           # SQLite 모델
    data/         # gy2bf_wbs.csv, zones.csv, conflict_rules.csv, 작업표준서
  frontend/
    src/scene/       # three.js 고로 3D·2D 도면
    src/views/       # 원청 화면, 협력사 화면
    src/components/  # 간트, 판정 패널, 챗봇
  samples/        # 합성 계획서(HWPX·엑셀·PDF), TBM 녹음 파일
  tests/
  README.md
```
