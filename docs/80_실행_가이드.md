# 한솥밥 실행 가이드 (Windows · macOS)

저장소를 처음 받은 PC에서 화면을 띄우고 음성인식(F7)까지 써 보는 순서입니다. 화면에 나오는 데이터는 모두 합성 데이터입니다.

## 0. 한눈에 보기

| 순서 | 할 일 | 한 번만 / 매번 |
|---|---|---|
| 1 | Git · Node.js · uv 설치 | 한 번만 |
| 2 | 저장소 받기 (`git clone`) | 한 번만 |
| 3 | 전달받은 `.env` 파일을 저장소 맨 위 폴더에 넣기 | 한 번만 |
| 4 | `npm run setup` | 한 번만 (코드를 새로 받으면 다시) |
| 5 | `npm run seed` | 처음 상태로 돌리고 싶을 때마다 |
| 6 | `npm run whisper` (음성인식을 쓸 때만, 창을 켜 둠) | 매번 |
| 7 | `npm run dev` (새 터미널) → `http://localhost:5173` | 매번 |

## 1. 필요한 프로그램과 버전

| 프로그램 | 버전 | 비고 |
|---|---|---|
| Git | 최신 | ZIP으로 받으면 `npm run setup` 이 멈춥니다. 반드시 `git clone` 으로 받습니다 |
| Node.js | **24 이상** | npm 11이 함께 설치됩니다. 24보다 낮으면 `npm run setup` 이 `EBADENGINE` 오류로 멈춥니다 |
| uv | 최신 | 파이썬 패키지·실행 도구입니다 |
| Python | 3.12 | **직접 설치하지 않습니다.** uv가 자동으로 받습니다 |
| 브라우저 | Chrome 또는 Edge 최신 | 마이크 녹음에 필요합니다 |
| Homebrew | 최신 | macOS만. 음성 서버 설치에 씁니다 |

음성 서버(whisper.cpp), ffmpeg, 음성 모델은 `npm run whisper` 가 알아서 받습니다(4.2절).

필요한 여유 공간은 약 3GB, 첫 실행에는 인터넷이 필요합니다.

### 1.1 Windows 설치

터미널은 **명령 프롬프트(cmd)** 를 권합니다. PowerShell은 `npm` 실행이 막혀 있는 PC가 있습니다(7절).

1. **Git**
   ```bat
   winget install Git.Git
   ```
2. **Node.js 24 이상**: [nodejs.org 다운로드](https://nodejs.org/ko/download)에서 Windows 설치 파일(.msi)을 받아 설치합니다. 여러 버전을 바꿔 쓰려면 [nvm-windows](https://github.com/coreybutler/nvm-windows/releases)를 설치한 뒤 다음을 실행합니다.
   ```bat
   nvm install 24
   nvm use 24
   ```
3. **uv**
   ```bat
   winget install astral-sh.uv
   ```
   winget이 없으면 PowerShell에서 다음을 실행합니다.
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
4. **터미널을 닫고 새로 연 뒤** 버전을 확인합니다.
   ```bat
   git --version
   node -v
   npm -v
   uv --version
   ```
   `node -v` 가 `v24` 이상, `npm -v` 가 `11` 이상이면 됩니다.

### 1.2 macOS 설치

1. **Homebrew**: [brew.sh](https://brew.sh) 첫 화면의 설치 명령을 터미널에 붙여 넣습니다.
2. **Git · Node.js · uv**
   ```bash
   brew install git node@24 uv
   ```
   `node@24` 는 설치 뒤 화면에 나오는 안내대로 PATH에 추가해야 `node` 명령이 잡힙니다. nvm을 쓴다면 저장소 폴더에서 `nvm install` 만 실행하면 `.nvmrc` 의 24를 받습니다.
3. 버전을 확인합니다.
   ```bash
   git --version && node -v && npm -v && uv --version
   ```

## 2. 저장소 받기

**OneDrive · Google Drive · Dropbox가 동기화하는 폴더(Windows의 바탕 화면·문서 폴더 포함) 안에는 받지 않습니다.** 동기화가 DB 파일을 깨뜨립니다. Windows는 `C:\Dev` 같은 폴더를 만들어 그 안에 받습니다.

```bat
git clone https://github.com/posco-hackathon/hansotbap.git
cd hansotbap
```

이후 명령은 모두 이 `hansotbap` 폴더(`package.json` 이 있는 곳)에서 실행합니다.

## 3. `.env` 파일 넣기

`.env` 는 API 키가 들어 있어 git에 올라가지 않습니다. **전달받은 `.env` 파일을 `hansotbap` 폴더 맨 위(`package.json` 옆)에 둡니다.**

- 파일 이름은 정확히 `.env` 여야 합니다. Windows 탐색기에서 `.env.txt` 로 저장되지 않았는지 확인합니다(탐색기 > 보기 > 파일 확장명 표시).
- 이 파일은 다른 사람에게 다시 보내거나 git에 올리지 않습니다.

`.env` 를 받지 못했다면 양식을 복사해 직접 채웁니다.

```bat
copy .env.example .env
```

macOS는 `cp .env.example .env` 입니다.

| 항목 | 필수 여부 | 쓰는 곳 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 필수 | 계획서 추출(F1), 조정안 문장(F4), 챗봇(F6), TBM 대조(F7) |
| `UNSLOTH_BASE_URL`, `UNSLOTH_API_KEY` | 선택 | 팀 로컬 LLM 노트북. 비우면 작업표준서 매칭(F8)은 규칙만으로 동작합니다 |
| 그 밖의 항목 | 기본값 그대로 | `.env.example` 의 설명 참고 |

## 4. 설치와 실행

### 4.1 설치와 DB 준비

```bat
npm run setup
npm run seed
```

- `npm run setup`: 루트·프론트 npm 패키지와 백엔드 파이썬 패키지를 lock 파일 그대로 설치합니다. 파이썬 3.12도 이때 받습니다.
- `npm run seed`: DB(`app/backend/hansotbap.db`)를 만들고 시연용 제출 이력 2건을 넣습니다. 여러 번 실행해도 같은 상태가 됩니다.

### 4.2 음성 서버 켜기 (음성인식을 쓸 때만)

```bat
npm run whisper
```

처음 한 번은 아래를 자동으로 받고, 그다음 서버를 켠 뒤 연결을 확인합니다. **이 창은 켜 둡니다**(끄기: Ctrl+C).

| 받는 것 | Windows | macOS |
|---|---|---|
| 음성 서버 `whisper-server` | whisper.cpp 공식 릴리스를 `.tools\whisper\` 에 풉니다. NVIDIA GPU가 있으면 CUDA판 | `brew install whisper-cpp` |
| ffmpeg (녹음 변환용) | `winget install Gyan.FFmpeg` | `brew install ffmpeg` |
| 음성 모델 (약 550MB) | `C:\Users\<이름>\models\` | `~/models/` |

- 서버 주소는 `http://127.0.0.1:8090/v1` 입니다(`.env` 의 `WHISPER_BASE_URL`).
- **Windows에서 ffmpeg가 방금 설치됐다면** Ctrl+C로 끄고 터미널을 새로 연 뒤 `npm run whisper` 를 다시 실행합니다. 그래야 ffmpeg가 잡혀 마이크 녹음(webm)을 받아쓸 수 있습니다.
- 설치·다운로드만 하고 서버는 켜지 않으려면 `npm run whisper -- --check` 를 씁니다.
- NVIDIA GPU가 없는 PC는 CPU로 돌아 녹음 길이의 약 2.5배가 걸립니다(7초 녹음 → 약 51초).

### 4.3 화면 켜기

**새 터미널**을 열어 `hansotbap` 폴더에서 실행합니다.

```bat
npm run dev
```

| 주소 | 내용 |
|---|---|
| `http://localhost:5173` | 화면 |
| `http://localhost:8000/api/health` | 서버 확인. `{"status":"ok", ...}` 가 나오면 정상 |
| `http://localhost:8000/docs` | API 문서 |

끌 때는 터미널에서 Ctrl+C를 누릅니다.

## 5. 써 보기

### 5.1 핵심 장면 (순서 위반 → 조정 → 해소)

1. 화면 오른쪽 위 **보는 사람**을 `가상-배관O` 로 바꿉니다.
2. `app/samples/겹침/S1_가상-배관O_가스라인_앞당김_작업계획서.hwpx` 를 올리고 제출합니다.
3. **보는 사람**을 원청으로 되돌려 충돌 목록에서 조정안을 적용하면 충돌이 해소됩니다.

다른 장면(S2~S7)과 올릴 파일은 [demo/시연_시나리오.md](demo/시연_시나리오.md)에 있습니다.

### 5.2 음성인식 (TBM 확인)

마이크 버튼은 **그 업체·그 날짜에 전달할 항목이 있을 때만** 눌립니다. 샘플 전달 항목을 먼저 넣습니다.

```bat
cd app\backend
uv run python ..\samples\seed_tbm_notices.py
cd ..\..
```

macOS는 `cd app/backend && uv run python ../samples/seed_tbm_notices.py && cd ../..` 입니다. `npm run seed` 를 다시 실행하면 이 항목도 지워지므로 그때마다 다시 넣습니다.

1. `npm run whisper` 창이 켜져 있는지 확인합니다.
2. 화면 맨 위의 날짜를 `2027-02-26` 으로 바꾸고 **TBM 확인** 탭을 엽니다. 원청으로 볼 때는 탭 안의 **협력사** 상자에서 `가상-배관O` 를 고르고, 협력사로 볼 때는 **보는 사람**을 `가상-배관O` 로 둡니다.
3. **참석자 녹음 동의를 받았습니다** 를 체크합니다.
4. 마이크 버튼을 누르고 말한 뒤, 다시 눌러 멈춥니다. 브라우저가 마이크 권한을 물으면 허용합니다.
5. 잠시 뒤 **받아쓴 내용** 칸에 글이 들어옵니다. 실시간 자막이 아니라 멈춘 뒤에 한 번에 받아씁니다.
6. **확인한 책임자** 를 적고 **체크리스트와 대조** 를 누르면 전달 항목별로 전달됨·빠짐이 표시됩니다.

마이크가 없으면 **받아쓴 내용** 을 펼쳐 **녹음 파일 올리기** 로 샘플 녹음 `app/samples/tbm/TBM_2027-02-26_가상-배관O_합성음성.m4a` 를 올립니다. 받는 형식은 wav · m4a · mp3 · webm · ogg 입니다. 음성 서버가 꺼져 있을 때는 같은 칸에 글을 직접 적어도 대조할 수 있습니다.

## 6. 명령어 모음

| 명령 | 하는 일 |
|---|---|
| `npm run setup` | 패키지 설치 (lock 파일 그대로) |
| `npm run seed` | DB를 비우고 시연용 제출 이력을 넣음 |
| `npm run db:reset` | DB를 비우기만 함 |
| `npm run whisper` | 음성 서버 준비·실행 (`-- --check` 준비만, `-- --cpu` CPU판 강제) |
| `npm run dev` | API(8000) + 화면(5173) 실행 |
| `npm run dev:api` / `npm run dev:web` | API만 / 화면만 실행 |
| `npm run models` | LLM 모델을 조회해 번호로 고름 (`.env` 에 저장) |
| `npm run chat:check` | 챗봇을 실제 LLM으로 점검 |
| `npm test` | 백엔드 테스트 |
| `npm run build` | 프론트 타입 검사·빌드 |

## 7. 막혔을 때

| 증상 | 해결 |
|---|---|
| `npm run setup` 에서 `EBADENGINE` | Node.js가 24보다 낮습니다. 24 이상을 설치하고 터미널을 새로 엽니다 |
| `npm run setup` 에서 `not in a git directory` | ZIP으로 받은 폴더입니다. `git clone` 으로 다시 받습니다 |
| `uv` 를 찾을 수 없음 | uv 설치 뒤 터미널을 새로 엽니다 |
| PowerShell에서 `npm` 이 "스크립트를 실행할 수 없습니다" | 명령 프롬프트(cmd)나 Git Bash에서 실행합니다 |
| 8000 포트를 이미 쓰고 있음 | 다른 포트로 띄웁니다. cmd: `set API_PORT=8002` 뒤에 `npm run dev` / PowerShell: `$env:API_PORT="8002"` 뒤에 `npm run dev` / macOS: `API_PORT=8002 npm run dev`. 화면 주소(5173)는 그대로입니다 |
| 화면은 뜨는데 추출·챗봇이 실패 | `.env` 위치(저장소 맨 위)·파일 이름·`ANTHROPIC_API_KEY` 를 확인하고 `npm run dev` 를 다시 켭니다 |
| 마이크 버튼이 눌리지 않음 | 전달 항목이 없습니다. 5.2절의 샘플 항목을 넣고 업체·날짜를 맞춥니다 |
| "마이크를 쓸 수 없습니다" | 주소가 `http://localhost:5173` 인지 확인합니다(IP 주소로 열면 브라우저가 마이크를 막습니다). 주소창의 자물쇠 아이콘에서 마이크를 허용합니다 |
| "음성 서버에 연결할 수 없습니다" | `npm run whisper` 창이 켜져 있는지 확인합니다 |
| 올린 녹음은 되는데 마이크 녹음만 받아쓰기 실패 | ffmpeg가 잡히지 않았습니다. 터미널을 새로 열어 `npm run whisper` 를 다시 켭니다 |
| Windows에서 `whisper-server` 가 바로 꺼짐 | `.tools` 폴더를 지우고 `npm run whisper -- --cpu` 로 CPU판을 받습니다 |
| 받아쓰기가 너무 오래 걸림 | CPU판은 녹음 길이의 2~3배가 걸립니다. 짧게 나눠 녹음합니다 |
| DB가 이상하거나 처음 상태로 돌리고 싶음 | `npm run seed` |
